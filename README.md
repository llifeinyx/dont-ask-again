# Don't Ask Again — прототип первого дня

Godot 4.7.2, GDScript. Внутреннее разрешение 640×360, масштабируется под окно.
Интерфейс ND-OS рисуется в отдельном окне вывода 1280×960 и выводится на стекло
кинескопа шейдером (изгиб, развёртка, свечение, блик лампы поверх).

## Запуск

1. Откройте Godot, нажмите **Import** и выберите `project.godot` в этой папке.
2. Запустите проект кнопкой **Run Project** (F5).

Фон комнаты — `art/room_front.jpg` (обрезка 16:9 сгенерированной картинки). Звуки синтезируются при старте.
Для эффекта звуков из-за спины лучше играть в наушниках.

## Управление

ND-OS на мониторе: панель сверху (глаз КОНТУРА, почта, часы), слева четыре программы и три закрытые.

| Где | Мышь | Клавиатура |
|---|---|---|
| Везде | клик по иконке слева | Ctrl+1…4 — переключить программу |
| Echo.daemon | клик по варианту ответа, по «[d] show details», по запросу в очереди | 1–3 выбрать, Enter подтвердить, D подробности, Tab следующий запрос |
| Kontur.watchdog | — | печатать ответ, Enter отправить |
| Проверка КОНТУРА (поверх всего) | закрыть нельзя | цифры кода, Enter |
| Feed.di | клик по варианту / клетке капчи | 1–9 ответ или клетка, Enter проверить капчу, A архив, S магазин, Esc назад |
| Seeya.legacy | клик по письму, по варианту ответа | ↑↓ выбрать письмо, 1–3 ответить |

- Разворот к вентиляции: кнопка `[ turn around ]` внизу. КОНТУР засчитывает разворот,
  только если глаз в панели открыт (он смотрит не всё время). Первый замеченный — предупреждение.
- Рычаг перезагрузки: при отключении света развернитесь и **зажмите** рычаг левой кнопкой мыши.

## Отладочные клавиши

| Клавиша | Действие |
|---|---|
| F2 | скорость x1 / x4 |
| F3 | промотать смену на 60 секунд |
| F11 | полноэкранный режим |

## Что есть в прототипе

- Договор с подписью (имя игрока), скрытый замер: сколько секунд читал, прокрутил ли до конца.
- Смена 15 минут (09:00–17:00 по игровым часам), 21 запрос Echo, 7 сообщений КОНТУРА, разметка без конца.
- Echo.daemon: терминал агента. 1 да / 2 да и больше не спрашивать / 3 нет. Вариант 2 одобряет все
  следующие запросы с тем же глаголом молча (например, «Delete…» → и удаление аккаунта I.R.).
- Kontur.watchdog: журнал, показатели, вопросы с вводом текста; проверки кода — модальное окно поверх всего.
- Feed.di: картинки, капчи, тексты; норма дня, потом бесконечный поток; контрольные вопросы; архив и магазин.
- Seeya.legacy: почта/мессенджер — соседка dana.v из 4-D, HR, автоответ I.R.; ответ можно поручить Echo.
- Разворот к вентиляции, звуки сзади, винт, пыль, блеск, записка.
- Отключение света: экран гаснет, в стекле отражение, рычаг, автоодобрение всех висящих запросов.
- Конец смены: отчёт КОНТУРА, «журнал наблюдения», ночь, геймовер «Вы уволены» (6 нарушений).

## Структура

```
data/day1.json            весь контент дня: запросы, КОНТУР, разметка, лор, магазин, почта, таймлайн
art/                      фон комнаты, карта света от экрана, иконки ND-OS
fonts/                    DejaVu Sans Mono, Ubuntu (лицензии рядом)
shaders/crt.gdshader      экран на стекле кинескопа
scripts/main.gd           поток: договор → смена → отчёты → ночь
scripts/shift.gd          смена: комната, экран, вентиляция, таймлайн, свет, рычаг
scripts/crt_screen.gd     стекло: шейдер + перевод кликов через изгиб в координаты ND-OS
scripts/ndos/ndos.gd      оболочка ND-OS: панель, лаунчер, уведомления, модальные окна, ввод
scripts/ndos/*_app.gd     четыре программы
scripts/ndos/nd_style.gd  палитра, шрифты, размеры
scripts/game_state.gd     состояние забега и скрытая статистика (autoload GameState)
scripts/sfx.gd            процедурный звук (autoload Sfx)
scripts/images.gd         процедурные картинки для разметки
scripts/vent_draw.gd      вид за спиной
scripts/debug_*.gd        только для автотестов
docs/                     дизайн, интерфейс, графика, задачи
tools/mockups/            скрипты макетов (Python/PIL) и утверждённые эталоны
```

Чтобы поменять тексты, тайминги или добавить запросы и письма, редактируйте `data/day1.json`:
поле `t` в таймлайне — секунда смены, когда событие происходит.

## Автотесты

```
Godot --headless --path . --fixed-fps 60 -- --smoke        прогон всего дня ботом
Godot --headless --path . --fixed-fps 60 -- --inputtest    клики и клавиши через изгиб экрана
Godot --path . -- --smoke --shots=/tmp/shots               скриншоты ключевых моментов
```
