# ND-OS — интерфейс монитора

Утверждено в октябре 2026 после долгих итераций. Эталонные макеты: `tools/mockups/reference/`.
Реализация: `scripts/ndos/`. Не меняй стиль без обсуждения.

## Принципы

- Это ОС, а не набор окон: **никаких рамок окон**, заголовков, кнопок свернуть/закрыть, ресайза и перетаскивания.
  Активная программа занимает всю область справа от лаунчера.
- **Ничего бутафорского**: нет меню программ, кнопки Dash, корзины, кнопки настроек. Всё, что видно, либо
  работает, либо явно заблокировано (замок).
- Стиль — старая Ubuntu (Unity / Ambiance) в теме **Bureau**: бежево-горчичные 80-е. Программы внутри —
  тёмный терминал, «как программист с Claude Code», без лишней красоты.
- Английский интерфейс, русская локализация позже. Шрифты: DejaVu Sans Mono (терминал), Ubuntu (панель).

## Каркас

- **Верхняя панель** — только системная: «ND-OS» слева; справа глаз КОНТУРА (открыт красный = смотрит,
  закрыт = нет), конверт (точка = есть непрочитанные), часы `Tue 09:41`. Клик по глазу открывает Kontur,
  по конверту — Seeya.
- **Лаунчер** слева: четыре программы со счётчиками и три заблокированные (Terminal, Files, Settings —
  с замком; клик даёт отказ «access restricted to the system»).
  - Echo.daemon — число ожидающих запросов;
  - Kontur.watchdog — красный «!», если ждёт ответа;
  - Feed.di — `labeled/quota`;
  - Seeya.legacy — число непрочитанных.
- **Уведомления** — тёмные плашки справа сверху, рамка по типу: красная KONTUR, горчичная echo.daemon
  (автоодобрение), серая seeya.legacy. Клик открывает программу.
- **Проверка КОНТУРА** — модальное окно по центру: всё затемнено, кроме глаза в панели; красная двойная рамка,
  код, поле ввода, полоса времени, «this check cannot be dismissed».

## Программы

| Программа | Суть | Ввод |
|---|---|---|
| Echo.daemon | Терминал CLI-агента. Шапка `echo.daemon 7.2.0 · session 0419 · /srv/nd/sector4`, лента (● реплики Echo, ● заголовок запроса + └ результат), рамка «Permission request» с подробностями ([d] показывает дифф: красные/зелёные строки), три варианта, таймер автоодобрения, строка «N more waiting», строка ввода `>` и подсказки | 1–3, ↑↓, Enter, D, Tab; клик по варианту |
| Kontur.watchdog | Шапка + «OBSERVING»/«idle», блок показателей (status, violations, response, turned away, shift time, next check), журнал с временем, вопрос в красной рамке с вводом текста и полосой времени | печать, Enter |
| Feed.di | Норма дня полосой, картинка с камеры (дизеринг) в рамке, вопрос и варианты справа, «recent» с пометками control ok/FAILED, ссылки на архив и магазин | 1–9, ↑↓ Enter, A, S, Esc; клик |
| Seeya.legacy | Как pine/mutt: инвертированная полоса заголовка, предупреждение об отключении, список писем (N = новое), переписка, рамка ответа | ↑↓, 1–3; клик |

Общее: Ctrl+1…4 переключает программы. Цвета: фон `#0D0D0C`, текст `#C6C4BC`, второстепенный `#706D66`,
линии `#46443F`, акцент (выбор) `#CDAC5C`, КОНТУР `#CE5C4A` / `#823C32`. Всё в `scripts/ndos/nd_style.gd`.

## Экран на стекле

- ND-OS рисуется в SubViewport 1280×960 (логика 640×480 ×2), шейдер `shaders/crt.gdshader` кладёт его на стекло
  фона: бочкообразный изгиб, скруглённые углы, развёртка, мягкость люминофора, свечение, лёгкая
  обесцвеченность и тёплый оттенок, блик лампы с фото поверх (screen blend).
- Клики проходят обратно через тот же изгиб (`scripts/crt_screen.gd: to_ui`). Если меняешь геометрию — меняй
  в обоих местах (константы GLASS/ACTIVE/BARREL и uniform-ы шейдера).
- Свет экрана на корпус и кружку — `art/screen_spill.png` с аддитивным смешиванием.

## История (что пробовали и отвергли)

Зелёный фосфор, CDE/X11, тайлинг, «Swiss», дашборды, киоск, «живой» вариант — не то. Белый современный —
не то. Ubuntu с окнами — убрали окна. Темы: Ambiance, Radiance, Bureau (выбрана), Clinic, Night, моно.
Echo в виде форм со штампами, чата, «фокуса», минималистичных карточек — отвергнуто; утверждён терминал.
Пачечные чекбоксы в Echo — «пока» оставлены в идеях, в терминале их нет.
